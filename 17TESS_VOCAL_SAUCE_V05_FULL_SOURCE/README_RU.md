# 17TESS VOCAL SAUCE — v0.5 RESPONSIVE + ORIGINAL CHORUS

**Собирается в Windows x64 VST3 через GitHub Actions (JUCE 8.0.7).**

## Изменения

- **Окно по умолчанию 790×702 вместо 1206×1072**. Все элементы масштабируются вместе с окном.
- В правом нижнем углу доступен ресайзер; DAW тоже может изменять размер через VST3/JUCE при поддержке хоста. Пропорции фиксированы, чтобы графика не искажалась. Размер от 595×529 до 1600×1422.
- **Chorus восстановлен из первой рабочей JUCE-версии v0.2**: исходный алгоритм и Wet, Delay/LFO, микс. Сравнение на тестовом сигнале: точное совпадение отсчётов при одинаковых настройках. Унаследованный параметр Chorus Width сохранён для совместимости состояний, но не используется этим исходным алгоритмом и больше не показан как настройка.
- **EQ:** крайний левый пиксель — High-Pass, крайний правый — Low-Pass; четыре центральные точки — parametric EQ ±36 dB. Оба фильтра второго порядка (12 dB/октава), отдельные включатели HP/LP в окне расширенных настроек и настройка резонанса (Q).
- При выборе/наведении на точку EQ отображаются частота (Hz/kHz), номер полосы и уровень dB (для обычных EQ-точек). Внизу графика добавлена логарифмическая шкала частот.
- HP и LP **выключены по умолчанию**, чтобы фильтры не окрашивали звук неожиданно. Клик/перетаскивание крайней точки включает соответствующий фильтр. Открыть EQ `+`, затем щёлкнуть `HP OFF / LP OFF`, чтобы их выключить обратно.
- Сохранение пользовательских `.17tesspreset` сохранено. Предустановленных пресетов нет.

## Как обновить существующий репозиторий `17tesss-coder/5`

В репозитории старый v0.4 проект находится **во вложенной папке** `17TESS_VOCAL_SAUCE_V04_READY_FOR_GITHUB`.

1. Скачай `17TESS_VOCAL_SAUCE_V05_UPDATE_FILES.zip` и распакуй.
2. В GitHub открой `17TESS_VOCAL_SAUCE_V04_READY_FOR_GITHUB/source` → `Add file` → `Upload files`.
3. Загрузи **четыре файла из папки `source` патча**: `DSPCore.h`, `PluginProcessor.cpp`, `PluginEditor.h`, `PluginEditor.cpp`; GitHub заменит старые. Нажми `Commit changes`.
4. В `17TESS_VOCAL_SAUCE_V04_READY_FOR_GITHUB` замени `CMakeLists.txt` из патча. Можно не менять, но в заголовке версии останется 0.4.
5. В КОРНЕ репозитория открой `.github/workflows/build-win64.yml`, нажми карандаш и замени содержимое файлом `build-win64-v05.yml` из патча. Если этот workflow уже собирал v0.4, ты можешь оставить его — новая версия компилируется так же, но архив будет называться v0.4. Рекомендуется заменить YAML.
6. После коммита проверь `Actions`. Дождись зелёной галочки. На странице сборки — `Summary` → `Artifacts` → скачай ZIP.
7. Закрой Cubase или FL Studio, сохрани резервную копию старого `.vst3`, затем замени всю папку `17TESS VOCAL SAUCE.vst3` в `C:\Program Files\Common Files\VST3\` на новую. Перезапусти DAW.

## Для нового репозитория

Если создаёшь отдельный репозиторий, распакуй `17TESS_VOCAL_SAUCE_V05_FULL_SOURCE.zip` и загрузи **его содержимое**, чтобы `CMakeLists.txt`, `source`, `assets` и `.github` оказались в корне репозитория. Workflow запускается при коммите в main или вручную через Actions.

## Технические замечания

- JUCE VST3 UI объявлен `setResizable(true, true)` и `setResizeLimits(...)`. В разных хостах внешний угол/рамка могут выглядеть по-разному. Внутренняя компоновка масштабируется при вызове `resized()`.
- Параметры `eq_gain1` и `eq_gain6` сохранены для совместимости состояний, но их значения больше не применяются как peak EQ; полосы 1/6 теперь фильтры.
- Код не компилировался в настоящей Visual Studio/Cubase в этой среде. Проверены отдельные DSP-тесты C++: bypass, chorus, cutoff-фильтры и отсутствие NaN в стресс-тестах.
- Уровень EQ ±36 dB экстремальный: проверяй громкость и не слушай сразу на высокой громкости.
